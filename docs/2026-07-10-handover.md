# Korangar Handover - 2026-07-10

This note captures the state of the client/server bring-up and the remaining work so the next session can resume without depending on chat history.

## What Was Completed

- Verified the client can talk to Hercules on `PACKETVER=20220406`.
- Fixed the macOS startup panic caused by the AppKit `drawRect:` / redraw race.
- Restored the original-client control shortcuts that had been missing or intercepted:
  - `F1`-`F9` hotbar
  - `F10` not stolen by the OS/windowing layer
  - `Alt+V`, `Alt+E`, `Alt+Q`, `Alt+S`, `Alt+Z`, `Alt+H`, `Alt+O`
  - `Ctrl+Tab` minimap toggle
  - `F11` close
  - `Alt+Shift+H` custom HUD toggle
- Implemented a durable English item-name path that does not depend on the original-client `System/itemInfo_EN.lua` tree.
- Replaced the broken external item-info linkage with bundled Hercules-derived names compiled into the client.
- Removed the temporary `KORANGAR_CLIENT_ROOT` workaround and the tracked symlink to `archive/System/itemInfo_EN.lua`.
- Documented the platform bring-up and original-control compatibility in the docs tree.

## What Was Verified Live

- Valid login.
- Character select shows existing characters.
- Map load succeeds after select.
- Click-to-move works for at least 10 tiles.
- Sit/stand works through the macOS-compatible `Home` binding.
- Basic melee works against a Poring:
  - sword cursor appears on hover
  - the character approaches and attacks
  - miss and damage numbers render
  - the character follows a moving Poring
  - no disconnect or freeze occurred during the test
- English item-name startup overlay now reports bundled Hercules names instead of the external client tree.

## Remaining Defects

- Inventory item hover still does not show identifying text/tooltip.
- Dragging items out of inventory still does not expose drop-to-ground behavior.
- Right-click inventory actions still need drop / stack / split handling.
- Ground-item label verification still needs to be re-run against the rebuilt client if that specific live confirmation is not already on record.
