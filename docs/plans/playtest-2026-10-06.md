## Questions from the notes

- **Ground skill modes** (Game Settings): *Aim + click* arms the skill and casts on the next click. *Quickcast* casts at the cursor the moment you press the key. *Hold + release* shows the area while the key is held and casts on release.
- **Framerate setting**: exists (`LimitFramerate`, `graphics/engine.rs`) and has never been checked live. Graphics Settings now has a Color filter (Off, Warm, Cool, Night, Mono) on the existing screen blit. Off leaves the frame unchanged. Not live.
- **Music default**: a missing value is 50%. A saved 100% is left at 100%, because it may be a choice. No migration.
- **Quest-giver icons**: the client draws `AddQuestEffect`. Campaign hubs already send it with `questinfo` (not `showevent`, which does nothing in `OnInit`). The novice chain only marked a quest that was already accepted. Not-started marks are now on the Wounded Swordsman, the island captain, Lumin, Izlude Carocc, and Hun. Not live.
- **Professor Hun**: renamed from `Criatura Academy Staff#0` to `Hun#0` (and `Hun#a`–`Hun#d`). Script-check passed. Not live until the map-server reloads scripts.
- **NPC names**: on by default (Game settings → Map and routes → Show NPC names). The name is drawn over the NPC, without the `#` suffix. Off restores the hover-only label. Not live.
- **Quest tracker**: the HUD lists tracked quests. The first is marked Primary and can Navigate when it has a map cell. Untrack is on the row. *First step towards a new world* (quest 7472) routes to Hun at izlude 122,207. The wreck quests on int_land and iz_int show the cell without a drawn route. Not live.
- **HUD level**: base level is on the HUD, above HP. Not live.
- **Monster target**: the Tab frame already shows bestiary level and `HP full` / `HP hidden` for the server's undamaged sentinel, or `HP current/max` once damaged. No change.
- **Hotbar**: drag a consumable onto a slot to replace it. Right-click → Add to hotbar replaces the slot that already has that item, or uses the first empty slot. The key name sits left of the button. The lock control is labeled Lock. Not live.
- **Equipped items**: a worn item shows `E` on its inventory slot. Not live.
- **Window opacity**: Game settings → HUD layout → Window opacity steps through 100%, 75%, 50%, and 25%. Not live.
- **Escape**: owner decided 2026-10-07: close the top window, then open the menu once nothing is left. Implemented as P0 in the plan.
- **Skill minus**: the skill tree minus refunds one spent point through `@refundskill`, or undoes a point that is only queued. The server refuses a rank another learned skill still needs. After the map-server is restarted it also refuses quest, wedding, spirit, guild, and non-novice Basic Skill. The cast-level arrows are unchanged. Automated tests pass, not live.
