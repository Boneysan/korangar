# Hercules Packet Reference — `PACKETVER=20220406`

This is the local cross-reference for mapping Hercules traffic into Korangar
packet definitions. It exists so packet-gap work does not depend on handover
memory or ad hoc terminal history.

## Source Of Truth

Hercules stores packet knowledge across several files:

| Need | Hercules source |
|---|---|
| Packet notation and direction letters | `~/GitHub/Hercules_RO/doc/packet_struct_notation.txt` |
| Incoming packet lengths for 2022 main clients | `~/GitHub/Hercules_RO/src/common/packets/packets2022_len_main.h` |
| Named map packet structs and modern header aliases | `~/GitHub/Hercules_RO/src/map/packets_struct.h` |
| Actual send/parse behavior and comments | `~/GitHub/Hercules_RO/src/map/clif.c` |
| Shuffled client-to-map opcodes for 20220406 | `~/GitHub/Hercules_RO/src/map/packets_shuffle_main.h` |
| Obfuscation key data if that decision changes | `~/GitHub/Hercules_RO/src/map/packets_keys_main.h` |

Do not copy the generated Hercules packet tables wholesale into this repository.
They are large, noisy, and owned by Hercules. Pull in the small packet rows we
actually use, with the Hercules file and symbol recorded.

## Lookup Workflow

1. Capture the first unknown incoming packet with `KORANGAR_PACKET_LOG=1`.
2. Find the fixed or variable length:

   ```bash
   rg -n "packetLen\\(0x0ae2|packetLen\\(0x09cd" \
     ~/GitHub/Hercules_RO/src/common/packets/packets2022_len_main.h
   ```

3. Find the semantic struct or send path:

   ```bash
   rg -n "0x0ae2|ZC_UI_OPEN|0x09cd|ZC_MSG_COLOR" \
     ~/GitHub/Hercules_RO/src/map/packets_struct.h \
     ~/GitHub/Hercules_RO/src/map/clif.c
   ```

4. For client-to-map packets, check the exact `PACKETVER == 20220406` block in
   `packets_shuffle_main.h`. Do not rely on a broader packet table if the opcode
   is shuffled.
5. Add the packet to `ragnarok-packets/src/lib.rs`.
6. Register it in `korangar-networking/src/packet_versions/version_20220406.rs`.
7. Add a parse or byte-layout test for every new layout.
8. Rerun with packet logging until the first unknown packet advances.

## Current Live Gap Findings

These rows come from the 2026-07-07 live Hercules/Korangar packet audit.

| Opcode | Direction | Hercules name | Length | Korangar status | Notes |
|---|---:|---|---:|---|---|
| `0x0A3B` | ZC | `ZC_EQUIPMENT_EFFECT` | variable | Defined + noop-registered | Already committed in `EquipmentEffectPacket`. |
| `0x097B` | ZC | `ZC_PERSONAL_INFOMATION` | variable | Defined + noop-registered | Hercules keeps the misspelled AEGIS-style name. |
| `0x0AE2` | ZC | `ZC_UI_OPEN` | 7 | Defined + noop-registered | Layout: UI type byte plus 32-bit data. Observed immediately after map load. |
| `0x09CD` | ZC | `ZC_MSG_COLOR` | 8 | Defined + noop-registered | Layout: message-table id plus BGR color. Observed in the same read as `0x0AE2`. |
| `0x009C` | ZC | `ZC_CHANGE_DIRECTION` | 9 | Defined + noop-registered | Entity id, head direction, body direction. Common around NPC/entity traffic. |
| `0x0B1A` | ZC | `ZC_USESKILL_ACK` | 29 | Defined + noop-registered | Modern replacement for the older `0x07FB` skill-use ack shape. |
| `0x0B0C` | ZC | `ZC_ADD_QUEST_EX` | 155 | Defined + noop-registered | `questAddType` for PACKETVER ≥ 20181017. Fixed frame: header, quest id, active flag, server/end time, objective count, then `MAX_QUEST_OBJECTIVES` (3) × 46-byte `packet_quest_hunt_sub`. Mapped as `QuestNotificationPacket4`. |
| `0x0B1B` | ZC | `ZC_NOTIFY_ACTORINIT` | 2 | Defined + noop-registered | Nearby modern actor-init packet; not the same as the observed `0x0B0C` frame. |

## Whisper Packet Targets

For 20220406 main, the incoming whisper payload is the modern `0x09DE`, not the
legacy `0x0097` header.

| Opcode | Direction | Hercules name/source | Length | Layout summary |
|---|---:|---|---:|---|
| `0x0096` | CZ | `CZ_WHISPER` via `packet_whisper_message` | variable | Packet length, target name, message. |
| `0x09DE` | ZC | `ZC_WHISPER` | variable | Packet length, sender character id, sender name, admin flag, message. |
| `0x0098` | ZC | `ZC_ACK_WHISPER` | 3 | One-byte result code. |

`0x0097` still appears in the generated length table, but Hercules maps
`ZC_WHISPER` to `0x09DE` for modern main clients. Do not implement `0x0097` for
20220406 unless live packet logs prove Hercules is emitting it.
