## Automated framing (2026-07-07, later session)

The packet-gap audit no longer has to be done one desync at a time. See
`docs/protocol/packet-length-fallbacks.md`:

- `tools/generate_packet_lengths.sh` scrapes Hercules' own `packetLen` tables at
  the server's `PACKETVER` (20190605, main) into
  `korangar-networking/src/packet_versions/lengths_20220406.rs` (1470 packets).
- `PacketHandler::register_length_fallbacks` consumes any known-length packet
  that has no dedicated handler yet, so the read buffer never desyncs; the
  packet still surfaces via `unknown_packet` for auditing. Wired into
  `register_map_server_packets`, registered last so it never shadows real
  handlers. Covered by unit tests in `ragnarok-packets/src/handler.rs`.

Framing is now automatic. Remaining work is purely *semantic*: model a packet by
hand only when the client needs its contents.
