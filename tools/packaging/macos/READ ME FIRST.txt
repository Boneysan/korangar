================================================================================
  SEAL CASCADE - Ragnarok Online for a few friends            (macOS)
================================================================================

WHAT THIS IS

  A private Ragnarok Online server and a custom game client, for this group
  of friends only. Everything you need is in this folder.

  You do not need the official RO client, Steam, or an account with Gravity.


--------------------------------------------------------------------------------
WHAT YOUR MAC NEEDS
--------------------------------------------------------------------------------

  An Apple Silicon Mac  -  M1, M2, M3, M4 or later.

  This build does NOT run on an Intel Mac. If your Mac has an Intel
  processor (Apple menu > About This Mac), tell the host - an Intel build
  is possible, it just is not in this download. Setup checks this first
  and says so plainly, rather than letting the game fail with a message
  that explains nothing.

  macOS 11 Big Sur or newer, and about 4 GB of free disk space.

  One free program: Tailscale. The game server is not on the public
  internet - it runs on the host's computer at their house, and Tailscale
  is how your Mac reaches it without them opening their home router to the
  world. A few clicks to install, and you sign in with a Google or
  Microsoft account. It is not a game launcher, there is no account with
  us, and it does not send your normal web browsing anywhere.

  Nothing else. No runtime, no Rosetta, no Java.


--------------------------------------------------------------------------------
FIRST TIME - DO THIS ONCE
--------------------------------------------------------------------------------

  1. Download the file the host sent you.

  2. Double-click the .zip. Finder unzips it into a folder beside it.

     Move that folder somewhere sensible first - your Desktop, or your home
     folder. Do not run it from inside the Downloads folder if you can help
     it; things get lost there.

  3. RIGHT-CLICK  Setup  and choose "Open".

     This step matters. macOS blocks anything downloaded from the internet
     that is not signed by a registered Apple developer, and this game is
     not. A plain double-click gives you a dialog with no way forward.
     Right-click and choose Open gives you the same dialog WITH an Open
     button. You only have to do this once - Setup clears the block for
     everything else in the folder.

     Setup unblocks the download, merges in the game data, checks every
     file, and starts the game. It can take a few minutes.

  4. Install Tailscale and accept the host's invite.

     Get it from  https://tailscale.com/download  and sign in. The host sends
     you an invite link; open it and accept, and their machine appears in your
     Tailscale list. Leave Tailscale running whenever you play - if it is not
     connected, the game reaches the login screen and then fails when it tries
     to enter the world.

  5. From then on, just double-click  Play.

  6. At the login screen, type a username ending in _create and a password:

       BobSmith_create

     There is no sign-up page. Typing a name that does not exist creates the
     account right there. The _create suffix is not part of your name and you
     only ever type it once: the account is called BobSmith, and that is what
     you log in with from then on.

     You pick your character's gender and appearance on the next screen, when
     you make the character.

     IMPORTANT: use a throwaway password you do not use anywhere else. See
     the PRIVACY note at the bottom of this file for why.


--------------------------------------------------------------------------------
IF YOU WERE SENT TWO DOWNLOADS INSTEAD
--------------------------------------------------------------------------------

  Some people get the game in two pieces, because the artwork is large and
  almost never changes:

      macOS     about 80 MB  - the game program. Changes with every update.
      Assets    about 3.7 GB - artwork, maps and music. Download once.

  Download both, unzip both, put the Assets folder NEXT TO the macOS folder,
  then right-click Setup inside the macOS folder and choose Open. Setup
  finds Assets and merges it in for you.

  When the host sends an update later, you only re-download the small one.


--------------------------------------------------------------------------------
UPDATING AN EXISTING INSTALL
--------------------------------------------------------------------------------

  Close the game. Download only Seal-Cascade-macOS.zip, the small client
  update. Unzip it separately. Copy the new korangar, .command launchers,
  READ ME FIRST.txt and SHA256SUMS-client into your existing game folder.
  For archive and client, merge their contents into the corresponding old
  subfolders. Do NOT choose Finder's Replace for the entire game or client
  folder; it can discard the files that the small update does not include.
  Keep the .grf files, BGM, lua_files.7z and SHA256SUMS-assets. Right-click
  Setup and choose Open to unblock the new files and verify the installation.

  Your characters and progress are on the server. The client update does not
  include saved passwords or personal interface settings.

  Text too small? During character creation click "Text size / interface
  scale", or open Menu > Interface Settings > Scaling. Try 1.3 or 1.5.
  Alt means the Option key on Mac. Ctrl means Control, not Command.
  Quest log: Ctrl+Q (all players). Party: Option+Z or Option+P.
  Inventory: Option+E. Commands: Ctrl+O. Close top window: Ctrl+W.
  Auto-pickup: ask the host to enable @autoloot 100 for your character;
  the number is a drop-rate threshold, not the percentage of loot to keep.


--------------------------------------------------------------------------------
THE THREE PROGRAMS IN THIS FOLDER
--------------------------------------------------------------------------------

  Setup     Run once, first. Unblocks the download, merges in the game data,
            checks every file, starts the game.

  Play      Starts the game. This is the one you use from then on.

  Verify    Checks every file against the checksum lists. Run it if the game
            behaves strangely after a download.

  Do not double-click the file called "korangar" directly. It looks like the
  game and it is, but started that way it cannot find any of its own data -
  Finder starts it in the wrong place. Play exists to fix exactly that.


--------------------------------------------------------------------------------
WHY THE FILE CHECKING MATTERS
--------------------------------------------------------------------------------

  Google Drive truncates large downloads, resumes them badly, and hands back
  a file that looks complete. A 3.7 GB folder is exactly the kind of thing
  that arrives subtly broken.

  When that happens, the game does not say "your download is damaged". It
  crashes somewhere unrelated, or a map is missing, or your character is
  invisible. You would report a bug that does not exist.

  So the folder ships two checksum lists - SHA256SUMS-client for the small
  half, SHA256SUMS-assets for the big one - and Setup and Verify check them.


--------------------------------------------------------------------------------
IF SOMETHING GOES WRONG
--------------------------------------------------------------------------------

  "Apple could not verify..." or "cannot be opened"
      Right-click the file and choose Open, instead of double-clicking.
      If Setup already ran, this should not happen again.

  Nothing happens when I double-click Play
      Open Terminal, drag the Play file into the window, press return. The
      error will be readable there. Send the host what it says.

  "the game data is missing"
      You have the small download but not Assets. See the two-downloads
      section above.

  The game starts but the screen is black or the window is tiny
      In game, open the menu and choose Graphics Settings. Display mode
      offers Windowed, Windowed Fullscreen and Exclusive Fullscreen.
      Option+Enter switches in and out of fullscreen at any time.

  I cannot connect
      Check Tailscale first: it must be running and signed in, and the host's
      machine must show up in its list. If Tailscale is fine, the server is
      probably not running - ask the host.

  I log in fine, then it fails when I pick my character
      This is almost always Tailscale. Logging in and entering the world are
      two separate connections, and the second one is the one that needs the
      host's machine reachable. Open Tailscale, check it says Connected, and
      try again.


--------------------------------------------------------------------------------
SENDING A LOG
--------------------------------------------------------------------------------

  Send korangar.log and korangar.log.previous from the game folder. They
  record startup stages, graphics details and errors, including panic
  backtraces. If the game folder is unwritable, look in $TMPDIR/korangar.
  If neither log exists, open Terminal, drag Play into the window and press
  return, then copy the error it prints. The failure may be before startup.
  Logs can contain local paths, account/character names and connection
  details. Review them before sharing publicly. Nothing is sent automatically.


--------------------------------------------------------------------------------
CONNECTING
--------------------------------------------------------------------------------

  The server address is already filled in for you, in client/server.ron. You
  do not need to type an address anywhere, and you should not edit that file -
  if the host moves the server they will send you a new copy of the small
  macOS folder.

  The address is a Tailscale one, which is why Tailscale has to be running.
  It is not reachable from the ordinary internet - only from machines that
  have joined the host's Tailscale network by invite. That is the point: the
  host does not have to open their home router to anyone.

  This works the same whether you are across the country or sitting in the
  host's house on their Wi-Fi. If you are on the same network as the host,
  Tailscale notices and sends the traffic straight across the local network
  rather than out to the internet and back, so being nearby is still faster.
  You still need Tailscale running either way.


--------------------------------------------------------------------------------
PRIVACY - PLEASE READ
--------------------------------------------------------------------------------

  Your password is sent to the server without encryption, and it is stored
  on the server in a form that is not meant to resist a determined attacker.
  This is normal for a small private RO server and it is not worth fixing
  for a group of friends, but it does mean one thing:

      Use a throwaway password. Not your email password, not a password you
      use anywhere else, not a variation of one.

  The client can remember your password for you. That is off by default, and
  if you turn it on it is saved unencrypted on your own Mac. Your choice.

  Nobody is collecting anything about you. There is no telemetry, no
  analytics and no account website.
